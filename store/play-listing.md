## アプリ名（30文字）

```
MAKE10 - 10をつくる計算パズル
```

端末のホーム画面に出るラベルは `MAKE10`（`AndroidManifest.xml` の `android:label`）。
ストア名と端末ラベルが違っていても審査上の問題はない。

## 簡単な説明（80文字）

```
4つの数字を ＋ − × ÷ で組み合わせて10をつくる計算パズル。広告なし・課金なし・完全オフライン。
```

## 詳しい説明（4000文字）

```
切符やナンバープレートの4桁で遊んだ「メイクテン」を、そのままアプリにしました。

表示された4つの数字を、＋ − × ÷ で組み合わせて、ちょうど10をつくる。ルールはそれだけです。

■ 遊び方
カードを1枚タップ → 演算子をタップ → もう1枚タップ。選んだ2枚が1枚に合体します。これを3回くり返して、最後に残った1枚が10になれば正解です。

出題される問題は、すべて「解ける組み合わせ」だけを事前に検証済み。答えのない問題で悩まされることはありません。

■ 2つのモード
・プラクティス — 時間制限なし。じっくり考えたいときに。ヒントと「答えを見る」が使えます。
・タイムアタック — 120秒で何問解けるか。ヒントなしの真剣勝負。ベストスコアは端末に記録されます。

どちらも「やさしい / ふつう / むずかしい」の3段階から選べます。難易度は、その問題の解きにくさをもとに分類しています。

■ ヒントは2段階
詰まったときは、1回目のヒントで「次に使う数字」、2回目で「次の一手の式」が出ます。答えを全部見てしまう前に、もう一歩だけ考えられます。

■ 記録が残る
難易度ごとのプレイ数・正解数・タイムアタックのベストスコアを、端末の中に保存します。少しずつ速くなっていくのが分かります。

■ 通信しません
このアプリはインターネットに接続しません。電波の入らない場所でも、機内モードでも、いつでも同じように遊べます。

・広告なし
・アプリ内課金なし
・アカウント登録なし
・個人情報の収集なし
・インターネット権限も要求しません

通勤電車のなか、待ち時間、寝る前のひと息に。1問はだいたい数十秒。頭の準備運動にどうぞ。

■ こんな方に
・計算パズル、数独、脳トレが好きな方
・広告に邪魔されずに遊びたい方
・オフラインで遊べるゲームを探している方
・お子さまの計算練習に使いたい方（四則演算と負の数が出てきます）

■ ルールの細かいところ
・使えるのは ＋ − × ÷ の4つ
・計算の途中は整数のみ。割り切れない割り算はできません（例: 7 ÷ 2 は不可）
・途中で負の数になるのは OK（例: 3 − 8 = −5）
・4つの数字はすべて1回ずつ使います
・数字をつなげて別の数にすること（1 と 2 で 12 など）はできません

ブラウザ版もあります: https://shiaco22.github.io/make10/
```

## データセーフティ（すべて「いいえ」）

| 質問 | 回答 |
| --- | --- |
| データを収集または共有しますか | いいえ |
| データは転送中に暗号化されますか | 該当なし（データを送信しない） |

端末から出ないデータは「収集」にあたらないため、いずれも「いいえ」で正しい。

## アプリのアクセス権（App access）

すべてのコンテンツが制限なしで利用可能。ログイン不要のため、審査用の
テストアカウントは不要 →「すべての機能が制限なく利用可能」を選択。

## 対象ユーザーとコンテンツ

対象年齢層は 13歳以上を含む全年齢で問題ないが、13歳未満を含めると
Families ポリシー（広告 SDK の制限など）の対象になる。本アプリは広告も
解析 SDK も持たないため、どちらを選んでも要件を満たす。

## 必要なスクリーンショット

Play Console の必須要件。**エミュレータか実機での撮影が必要**（このリポジトリでは生成できない）。

- スマートフォン: 最低2枚、最大8枚。16:9 または 9:16、短辺 1080px 以上を推奨
- 7インチ / 10インチ タブレット: 任意だが、タブレット対応を謳うなら各1枚以上

撮り推奨の画面:
1. ホーム画面（プラクティス / タイムアタック / 統計）
2. プレイ中の盤面（カード選択中）
3. ヒント表示中（式が出ている状態）
4. 正解画面
5. タイムアタックの残り時間表示
6. 統計画面

撮り方（エミュレータ）:

```
flutter run --release
# 端末側で撮影、または
adb exec-out screencap -p > store/screenshots/01-home.png
```
