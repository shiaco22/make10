# Google Play ストア掲載情報（MAKE10）

Play Console の各欄にそのまま貼れる形で置いてある。文字数はカッコ内が上限。
更新したら `python3 tool/branding/check_listing.py` で長さを確認すること。

スクリーンショットは `store/android/` にある（`store/android/README.md` を参照）。
アイコンとフィーチャーグラフィックは `tool/branding/generate_icons.py` が生成する。

> コンテンツレーティングのいずれも、それを前提にした内容になっている。

## アプリ名（30文字）

```
MAKE10 - 10をつくる計算パズル
```

端末のホーム画面に出るラベルは `MAKE10`（`AndroidManifest.xml` の `android:label`）。
ストア名と端末ラベルが違っていても審査上の問題はない。

## 簡単な説明（80文字）

```
4つの数字を ＋ − × ÷ で組み合わせて10をつくる計算パズル。出題はすべて解けると検証済み。
```

## 詳しい説明（4000文字）

```
切符やナンバープレートの4桁で遊んだ「メイクテン」を、そのままアプリにしました。

表示された4つの数字を、＋ − × ÷ で組み合わせて、ちょうど10をつくる。ルールはそれだけです。

■ 遊び方
カードを1枚タップ → 演算子をタップ → もう1枚タップ。選んだ2枚が1枚に合体します。これを3回くり返して、最後に残った1枚が10になれば正解です。

出題される問題は、すべて「解ける組み合わせ」だけを事前に検証済み。答えのない問題で悩まされることはありません。

■ 2つのモード
・プラクティス — 時間制限なし。じっくり考えたいときに。ヒントと「答えを見る」が使えます。
・タイムアタック — 120秒で何問解けるか。ヒントなしの真剣勝負。ベストスコアは端末に記録されます。

どちらも「やさしい / ふつう / むずかしい」の3段階から選べます。難易度は、その問題の解きにくさをもとに分類しています。

■ ヒントは2段階
詰まったときは、1回目のヒントで「次に使う数字」、2回目で「次の一手の式」が出ます。答えを全部見てしまう前に、もう一歩だけ考えられます。

■ 記録が残る
難易度ごとのプレイ数・正解数・タイムアタックのベストスコアを、端末の中に保存します。少しずつ速くなっていくのが分かります。

■ 広告と、広告を消す方法
無料でお使いいただくため、プラクティスを数問クリアするごとと、タイムアタックの結果画面で、全画面広告を表示します。問題を解いている最中に広告が割り込むことはありません。

広告が気になる場合は、アプリ内から「広告を消す」を購入できます。月額プランと買い切りプランのどちらかを選べ、購入後は広告の読み込み自体を行いません。

■ 通信について
パズルの出題・採点・統計は、すべて端末の中だけで完結しています。通信するのは広告の取得と購入の確認のときだけなので、オフラインでもそのまま遊べます（その間、広告は表示されません）。

アカウント登録は不要です。氏名やメールアドレスなど、あなたを特定する情報は集めません。

通勤電車のなか、待ち時間、寝る前のひと息に。1問はだいたい数十秒。頭の準備運動にどうぞ。

■ こんな方に
・計算パズル、数独、脳トレが好きな方
・オフラインで遊べるゲームを探している方
・お子さまの計算練習に使いたい方（四則演算と負の数が出てきます）

■ ルールの細かいところ
・使えるのは ＋ − × ÷ の4つ
・計算の途中は整数のみ。割り切れない割り算はできません（例: 7 ÷ 2 は不可）
・途中で負の数になるのは OK（例: 3 − 8 = −5）
・4つの数字はすべて1回ずつ使います
・数字をつなげて別の数にすること（1 と 2 で 12 など）はできません

ブラウザ版もあります（広告なし）: https://shiaco22.github.io/make10/
```

## アプリ内購入（Play Console で商品を作成する）

商品 ID は `lib/monetization/billing/product_ids.dart` が唯一の定義元。
**Play Console 側の ID をこれと1文字違わず一致させること**（違うと購入できない）。

| 商品 ID | 種別 | 価格 | 備考 |
| --- | --- | --- | --- |
| `make10_noads_monthly` | 定期購入 | ¥300 / 月 | ベースプラン ID は `monthly` |
| `make10_noads_lifetime` | 1回限りの購入（管理対象） | ¥980 | 買い切り |

定期購入は「収益化 → 定期購入」、買い切りは「収益化 → アプリ内アイテム」から作成する。
どちらも**有効化**を忘れないこと。作成しただけでは購入フローが動かない。

## データセーフティ

広告（Google AdMob）を入れているため、「収集しない」では**申告として誤り**になる。
以下は AdMob の標準的な構成に対する申告内容。
[Google の AdMob 向けデータ開示ガイダンス](https://support.google.com/admob/answer/11115302)
を最終確認すること。

| 質問 | 回答 |
| --- | --- |
| データを収集または共有しますか | **はい** |
| データは転送中に暗号化されますか | はい |
| ユーザーはデータの削除をリクエストできますか | いいえ（端末の設定から広告 ID をリセット可能） |

収集・共有するデータ（2026-10-19 に Play Console へ入力した内容。名称は Console の表記）:

| データ型 | 収集 | 共有 | 一時的に処理 | 必須か | 収集の目的 | 共有の目的 |
| --- | --- | --- | --- | --- | --- | --- |
| デバイスまたはその他の ID（広告 ID） | はい | はい | いいえ | 必須 | アプリの機能、広告・マーケティング、不正行為防止 | 広告・マーケティング、不正行為防止 |
| 位置情報 → おおよその現在地 | はい | はい | いいえ | 必須 | アプリの機能、分析、広告・マーケティング | 広告・マーケティング |
| アプリのアクティビティ → アプリのインタラクション数 | はい | はい | いいえ | 必須 | 分析、広告・マーケティング | 分析、広告・マーケティング |
| アプリの情報、パフォーマンス → クラッシュログ、診断情報 | はい | はい | いいえ | 必須 | 分析、不正行為防止 | 分析、不正行為防止 |

**「一時的に処理」はすべて「いいえ」にする。** 「はい」と答えたデータはストアの
掲載情報に表示されない。以前は広告 ID とおおよその現在地が「はい」になっていて、
ストア上は何も収集していないように見えていた。AdMob はこれらを広告配信のために
保持するので、一時的な処理にはあたらない。

広告 ID と現在地の「収集の目的」に入っている「アプリの機能」（現在地は「分析」も）は、
以前の申告から残しているもの。MAKE10 はどちらもアプリの機能には使っていないので、
外すのが正確だが、開示を減らす変更なのでまだ外していない。

**収集しないもの**: 氏名、メールアドレス、電話番号、住所、正確な位置情報、
連絡先、写真・動画、音声、ファイル、健康情報、購入履歴（決済は Google Play が
処理し、アプリは「購入済みかどうか」の状態のみを端末内に保持する）。

ゲームの統計・ベストスコア・出題履歴は端末から出ないため、Play の定義では
「収集」にあたらない。

## 広告 ID

「アプリで広告 ID を使用していますか？」→ **はい**

目的: **広告、マーケティング** と **不正行為防止、セキュリティ、コンプライアンス**

アプリのマニフェストには書いていないが、`google_mobile_ads` が持ち込む
`com.google.android.gms.permission.AD_ID` がリリースビルドの統合マニフェストに
入る。この権限がある限り答えは「はい」で、Play Console もそう案内してくる。
この申告が無いと、Android 13 以降をターゲットにしたリリースを審査に出せない。

## 対象ユーザーと年齢層

**13歳以上を対象に設定することを推奨する。** 13歳未満を含めると Play の
ファミリー向けポリシーの対象になり、広告 SDK をファミリー向け認定のものに
限定し、広告 ID を使わない構成にする必要がある。現在の AdMob の
標準構成のままでは要件を満たせない。

## ログインの詳細（旧「アプリのアクセス権」）

**「アプリの一部にアクセス制限がありますか？」→ はい** を選び、下の手順文を貼る。
認証情報の欄は空のままでよい。

判断の理由: このアプリにログインは無く、ペイウォールの向こうにあるコンテンツも
無い。パズル・両モード・全難易度・ヒント・統計は購入なしで全部触れるので、
Google のヘルプが言う「定期購入者しかアクセスできない機能やコンテンツ」には
あたらない。**それでも「はい」にするのは、Play Console の画面がトリガーとして
「1回限りのアイテム、メンバーシップ、定期購入」を明示的に挙げているため。**
手順文を添えれば審査側に不足は無く、「いいえ」が誤申告と判断されるリスクだけを
消せる。

手順欄（**英語で書く必要がある。500文字以内**）:

```
No login or account is required. Every part of the app is available immediately after install: both game modes (Practice and Time Attack), all three difficulty levels, hints, "view answer" and the statistics screen.

The optional in-app purchase (make10_noads_monthly / make10_noads_lifetime) only disables the interstitial ads. It unlocks no content, screen or feature, so nothing is behind a paywall and no test credentials are needed.
```
